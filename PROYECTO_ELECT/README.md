# LSC / VISION — Versión 30

Cambios exclusivamente en la interfaz de presentación y el cierre:

- La marca del menú principal pasa de LSC / VISION a **UTP**.
- Se elimina el pie de página descriptivo bajo la despedida.
- Se elimina la barra inferior de flechas y el botón Guion. La navegación por puntos y teclado se mantiene; las notas continúan accesibles con la tecla N, sin control visible.
- La escena 15 muestra, antes de «¡MUCHAS GRACIAS!», el informe académico original en una tarjeta de presentación con portada real. Hay un visor de lectura grande y descarga del PDF completo de 34 páginas.
- Se conservan las 15 escenas, los modelos y todas las animaciones tridimensionales de V29.

## Cómo ejecutar

Sirve `index.html` desde localhost, con `assets` en la misma carpeta.
El visor integrado usa el visor PDF nativo del navegador; también hay opción para abrir el PDF en otra pestaña.
Usa Ctrl+F5 para evitar archivos antiguos de caché.

El PDF se incluye sin modificar. El proyecto sigue siendo una propuesta de diseño, sin prototipo validado.
